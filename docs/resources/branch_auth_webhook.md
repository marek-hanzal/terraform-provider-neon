# neon_branch_auth_webhook (Resource)

Owns one existing managed Auth integration's webhook configuration. Deploy its handler first. Destroy disables delivery before dependent infrastructure is removed; accounts and sessions remain intact. Manage exactly one resource per branch.

```terraform
resource "neon_branch_auth_webhook" "mail" {
  project_id      = neon_branch_auth.app.project_id
  branch_id       = neon_branch_auth.app.branch_id
  database_name   = neon_branch_auth.app.database_name
  enabled         = true
  webhook_url     = "${neon_function.api.invocation_url}/api/auth/email"
  enabled_events  = ["send.magic_link"]
  timeout_seconds = 5
}
```

Managed Better Auth exposes one webhook configuration per branch. This resource owns its complete configuration independently from `neon_branch_auth_config`. Reference a deployed Function URL to enable delivery only after its handler exists. Native Function URLs require no custom-domain DNS/TLS dependency; email links can still use the application's public domain.

Create and Update use native PUT, Read uses GET, and Destroy uses PUT with `enabled = false`, restoring built-in mail delivery before the handler is torn down. No account/session operations or test emails are performed. A changed Auth integration identity fails refresh/update/destroy rather than configuring or disabling another integration. Import uses `PROJECT_ID/BRANCH_ID/DATABASE_NAME`.

Neon retries blocking mail events at most three times within a total of 15 seconds. The handler must be idempotent on the signed event ID and must acknowledge only after its transport accepts the email. HTTPS, public DNS and no redirect are enforced by Neon. Enabling mail events replaces their managed email delivery.

## Schema

### Required

- `branch_id` (String) Neon branch ID.
- `database_name` (String) Database of the existing managed Better Auth integration.
- `enabled` (Boolean) Enable webhook delivery. Disabling restores built-in delivery for subscribed mail events.
- `enabled_events` (Set of String) Authoritative set of subscribed Neon webhook event names.
- `project_id` (String) Neon project ID.
- `timeout_seconds` (Number) Per-attempt timeout, 1–10 seconds. Neon caps all three attempts at 15 seconds.
- `webhook_url` (String) Public HTTPS handler URL. No credentials or fragments; Neon enforces public DNS and rejects redirects.

### Read-Only

- `auth_provider_project_id` (String) Integration identity; refuses to configure a replacement integration.
- `id` (String) Webhook identity: PROJECT_ID/BRANCH_ID/DATABASE_NAME.
